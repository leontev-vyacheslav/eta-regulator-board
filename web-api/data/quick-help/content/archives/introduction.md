### Архивы

Программное обеспечение **контроллера** имеет в своей реализации функцию сохранения результатов измерения параметров состояния тепловой системы. **Архивы** представляют собой файл в формате gzip в котором располагается файл содержимого архива с часовыми отсчетами параметров состояния в формате json.
