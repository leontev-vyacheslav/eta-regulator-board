### Режим ручного управления

определяет, каким образом управляется регулирующий клапан в ручном режиме. Возможными вариантами настройки являются:

- клапан;
- температура.

В случае выбора «клапан» пользователь может самостоятельно подавать команды на открытие/закрытие клапана. В случае выбора «температура» контроллер производит поддержание температуры, определенной параметром «**Уставка поддерживаемой темп. ручного режима, °C**».
